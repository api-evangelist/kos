# Kos

Kos (Kosai, Inc.) builds a "virtual finance employee" — an AI agent with its own workstation, org identity, software licenses, RBAC and audit logs — that completes finance and back-office workflows for capital- and inventory-heavy operators in datacenters, defense, energy, long-lead equipment, space and contracting. Kos reviews pay applications and vendor invoices against GMP contracts, generates and closes out purchase orders inside a customer's ERP, and is taught new workflows over screenshare.

Kos is reached over email, Slack, Teams, phone and Zoom. As of 2026-07-19 the company publishes **no public API, developer portal, SDK, CLI, webhook surface or `/.well-known/` discovery documents** — by design ("There's no UI or app to use Kos; it's a fully virtual human"). This profile therefore carries company identity and security posture rather than API artifacts.
